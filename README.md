# ☕ Starbucks Beverage Analytics Dashboard | Power BI

## 📊 Project Overview

This project presents an interactive Power BI dashboard analyzing Starbucks beverages based on nutritional information, caffeine content, protein levels, beverage categories, and preparation types.

The dashboard provides insights into beverage composition and nutritional characteristics through interactive visualizations and filters.

## 🎯 Objectives

- Analyze caffeine content across different beverage categories.
- Identify beverages with the highest caffeine content.
- Compare protein levels across beverage types.
- Explore beverage distribution by category.
- Analyze beverage preparation methods.
- Create an interactive and visually appealing dashboard.

## 🛠️ Tools & Technologies

- Power BI Desktop
- Microsoft Excel
- DAX
- Data Visualization
- Data Analysis

## 📈 Dashboard Features

- **Beverage Category Distribution:** Visualizes beverage distribution across categories using a donut chart.
- **Average Caffeine by Category:** Compares caffeine content across beverage categories.
- **Top 5 Highest Caffeine Beverages:** Highlights beverages with the highest caffeine content.
- **Protein Analysis:** Compares protein levels across different beverages.
- **Beverage Preparation Filter:** Allows users to filter the dashboard by preparation type.
- **Interactive Dashboard:** Provides dynamic filtering and cross-visual interactions.

## 📊 Key Metrics

- Average Caffeine Content
- Average Protein Content
- Beverage Category Distribution
- Highest Caffeine Beverages
- Nutritional Comparison
